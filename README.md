# SMART-CPU-SCHEDULER
Smart CPU Scheduling System with Machine Learning-based prediction, interactive simulation, and performance visualization.
This project presents an intelligent CPU scheduling simulator that combines traditional Operating System algorithms with Machine Learning to dynamically select the most efficient scheduling strategy.

The system allows users to input process details such as arrival time, burst time, and priority, and evaluates multiple scheduling algorithms including First Come First Serve (FCFS), Shortest Job First (SJF), Priority Scheduling, and Round Robin. A Machine Learning model analyzes the input data and predicts the best-performing algorithm for the given scenario.

The application is developed using Python and Streamlit, providing an interactive web interface with features such as Gantt chart visualization, performance comparison graphs, and real-time system monitoring.
